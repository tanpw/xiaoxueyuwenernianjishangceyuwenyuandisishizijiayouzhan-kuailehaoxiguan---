## 儿歌全文 · 《快乐好习惯》

```
天色初晓日初昌，
铺好床铺心欢畅。
起床伸腰轻声调，
硬板床上睡得香。

卧室清洁要做到，
玩乐时间限得牢。
乘车礼让守规矩，
售票记得付钱喽！
```

儿歌特点：
- **押韵顺口**（昌/畅/调/香；到/牢/矩/喽），朗朗上口，便于朗读和记忆。
- **寓教于乐**，将 8 个生字全部融入生活场景，同时渗透**早睡早起、整理卫生、守时自律、文明乘车**的好习惯。

## 建议教学流程

1. **识字导入**：展示生字卡片或板书「昌、铺、调、硬、卧、限、乘、售」，让学生观察字形。
2. **初读儿歌**：播放 `《快乐好习惯》.mp3`，让学生边听边指读，整体感知韵脚。
3. **图文对应**：逐屏展示 `1天.png` ~ `8售.png` 插图，请学生猜测并读出对应的诗句，在语境中识字。
4. **字词句拓展**：用每个生字组词、造短句（如「昌——昌盛」「铺——铺路」「调——调节」）。
5. **书写指导**：重点讲解难写字的笔画与结构（如「售」的上下结构、「卧」的部首「臣」）。
6. **表演朗读**：全班拍手打节拍齐读，或分组分句朗读，加深记忆。
